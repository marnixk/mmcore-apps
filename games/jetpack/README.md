# Jetpack (mmcore port)

**JETPACK — a port for mmcore**

Original game **Jetpack** (1993) by **Adept Software** / **Adam Pedersen**.  
Freeware: [adeptsoftware.com/jetpack/](https://www.adeptsoftware.com/jetpack/)

This directory will hold the mmcore implementation after art and mockups are approved (phase 2). Phase 1 extraction and design live under [`tools/jetpack/`](../../tools/jetpack/).

Tetris (mmcore edition) - asset list
=========================================================
Art direction: Soviet Elektronika-60 homage - St Basil's Cathedral and the Kremlin wall
under a night sky, red lacquer and gold Khokhloma panels, standard guideline piece colours
(I cyan, O yellow, T purple, S green, Z red, J blue, L orange). Hand-built pixel art,
hard Bayer dithering, no antialiasing, alpha 0/255 only.

gfx/  (PNG, RGBA; alpha 0 = skipped by LOAD PNG; no sprite pixel is pure black, so
       BLIT ori 4 transparency works from a CLS-black sheet page)
  game_WxH.png     game scene (backdrop, well frame + empty well, HOLD / NEXT / STATS
                   panels, St Basil's arch window)
  dim_WxH.png      game scene dimmed, well hidden (pause and dialogs)
  intro_WxH.png    title screen (TETRIS block title, MMCORE EDITION ribbon, menu panels)
  scores_WxH.png   high-score screen (3 difficulty columns)
                   WxH = 1366x768 683x384 1920x1080 1280x720 1024x768 800x600 848x480 640x480
  sheet_s<sc>c<cell>.png
                   sprite sheet per scale / board cell: small + big pixel fonts (colour rows),
                   tiles, ghost tiles, well cell + 4 line-clear flash frames, mini tiles,
                   keycap arrows. s2c15 s1c15 s3c15 s1c26 s1c20
  layout.txt       layout summary (the code uses includes/layouts.inc)

sfx/  empty - the game is silent (includes/music.inc: MUSIC_ON = 0, SFX_ON = 0) so it can
      run alongside JUKE; mmcore has one global audio player and any PLAY command would
      stop it.

tetris.hi          created on the first high score (difficulty,score,level,name per line,
                   top 10 per difficulty). Not shipped.

All gfx files are generated by the art generator (Python + Pillow, kept out of the app
folder); every resolution has its own pre-scaled set, nothing is scaled at run time.

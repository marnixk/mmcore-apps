# Games

Games for mmcore (MMBasic, Colour Maximite 2 style). Each game lives in its
own folder; run it from the mmcore prompt with the RUN line shown (RUN changes
into the game's folder, so its gfx/, sfx/ and data files resolve relative to it).

| Game | Folder | Run |
|------|--------|-----|
| Sudoku Grove - a calm forest sudoku | [sudoku/](sudoku/) | `RUN "games/sudoku/sudoku.bas"` |
| Tetris - mmcore edition, Soviet-style falling blocks | [tetris/](tetris/) | `RUN "games/tetris/tetris.bas"` |
| Snake - mmcore edition, 10 garden levels, high scores | [snake/](snake/) | `RUN "games/snake/snake.bas"` |
| Void Runner - Flappy-style space flight through asteroid and laser gaps, speed ramps up | [voidrunner/](voidrunner/) | `RUN "games/voidrunner/voidrunner.bas"` |
| TRONIX - Xonix on the neon Grid: claim 75% of the grid, dodge orbs and sentinels | [tronix/](tronix/) | `RUN "games/tronix/tronix.bas"` |
| Core Caving - Boulder Dash style digging: 16 caves + 4 bonus caves, boulders, fireflies, butterflies, magic walls, amoeba | [corecaving/](corecaving/) | `RUN "games/corecaving/corecaving.bas"` |
| Circuit Quest - Chip's Challenge style puzzles in a silicon lab: 20 levels, keycards and doors, blocks, boots, ice, conveyors, toggle walls, traps, teleports, tanks, bombs, hidden walls | [circuitquest/](circuitquest/) | `RUN "games/circuitquest/circuitquest.bas"` |

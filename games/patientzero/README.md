# Patient Zero: Bless You

Jerry walks a 32 by 18 block and cures the people on it with a sneeze. Hold Z to charge, press V to release. A sneeze reaches both sides. Standing in a puddle refills a spent sneeze. Five lives. Each level has a cure target, then a clear screen, then the next street.

Run from this directory: `RUN "main.bas"`. High scores are kept in `C:/.patientzero`. The game is silent.

Arrow keys move. Esc or P pauses. Q on the pause screen returns to the title.

Levels in this build: Street, Rainy street, Hospital, Subway. Park, rooftops, blackout and the mall need tile art that is not in the sheets yet. After the subway the four levels repeat, with faster spawns and a higher cure target.

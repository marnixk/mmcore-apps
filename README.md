# mmcore-apps

Apps and games for mmcore.

## Games

Games for mmcore (MMBasic, Colour Maximite 2 style). Each game lives in its
own folder; run it from the mmcore prompt with the RUN line shown (RUN changes
into the game's folder, so its gfx/, sfx/ and data files resolve relative to it).
